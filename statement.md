# Project Statement

## Problem
Students often maintain assignments, deadlines, and study time in separate notes. This makes it difficult to identify the most urgent work and measure productivity.

## Proposed Solution
Smart Student Task & Productivity Tracker is a Java command-line application that centralizes academic tasks and study sessions, stores data persistently in SQLite, and recommends a pending task using a transparent priority score.

## Target Users
Students who want a lightweight terminal-based academic planner.

## Scope
The first version covers task CRUD operations, task status, deadline tracking, smart recommendations, study-session recording, productivity analytics, and database backup. It intentionally avoids cloud synchronization and external notification services.

## High-Level Features
- Task creation with subject, priority, deadline, and effort.
- Status tracking and deletion.
- Smart next-task recommendation.
- Study-session tracking.
- Productivity dashboard.
- Upcoming/overdue task view.
- SQLite persistence and database backup.
